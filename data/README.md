# Data directory

This repository does not redistribute raw or derived individual-level survey data.

To run the scripts, place locally obtained files in this directory:

- `kyrbs2020_2024_primary_grade_comparable_grade3_6_40predictors_input.csv`: model-ready KYRBS development input generated from the public KYRBS raw-data files under applicable data-use terms.
- `yrbss_raw/2023XXH-SPSS.sps`: CDC YRBSS 2023 SPSS syntax file.
- `yrbss_raw/XXH2023_YRBS_Data.dat`: CDC YRBSS 2023 fixed-width ASCII data file.

The YRBSS model-input CSV is generated by:

```bash
python analysis/build_yrbss2023_selected_40predictor_reference.py
```
